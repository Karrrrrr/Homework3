Промпт для милого дизайна:
Сгенерируй интерфейс мобильного приложения для отслеживания подписок на платные сервисы. В приложении должен быть список подписок, каждую из которых можно редактировать, удалять, а также создавать новые. Также в приложении должен быть раздел со статистикой потраченных средств на подписки. Стиль приложения милый. Элементы интерфейса должны быть спокойных цветов. В приложении должен появляться милый зверёк-маскот, который будет помогать пользователю использовать приложение. Меню приложения в выдвигающейся боковой панели слева

Особенности дизайна:
	- милый стиль
	- спокойные цвета
	- зверёк-маскот, который помогает пользователю разобраться в приложении
	- меню приложения в выдвигающейся боковой панели слева
	- милые надписи

Преимущества:
	- подсказки по приложению в виде милого зверька-маскота
	- спокойные цвета расслабляют

Недостатки:
	- дизайн рассчитан преимущественно на пользователей женского пола
	- зверёк-маскот может раздражать некоторых пользователей
