Промпт для яркого дизайна:
Сгенерируй интерфейс мобильного приложения для отслеживания подписок на платные сервисы. В приложении должен быть список подписок, каждую из которых можно редактировать, удалять, а также создавать новые. Также в приложении должен быть раздел со статистикой потраченных средств на подписки. Стиль приложения яркий. На экране должны быть яркие контрастные элементы. Формы элементов должны быть сильно сгруглёнными. Интерфейс приложения должен быть в формате Notion, то есть все сущности открываются на отдельных страницах

Особенности дизайна:
	- яркие контрастные цвета элементов интерфейса
	- сильно скруглённые формы элементов
	- у каждой сущности отдельная страница
	- плавающее меню в нижней части экрана
	- неформальный стиль надписей
	- крупный жирный шрифт

Преимущества:
	- модный дизайн, который привлекает внимание
	- выделенные жирным числа сразу фокусируют на себе внимание

Недостатки:
	- слишком яркие цвета могут напрягать зрение
	- крупный шрифт занимает слишком много места на экане
