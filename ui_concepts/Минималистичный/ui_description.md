Промпт для минималистичного дизайна:
Сгенерируй интерфейс мобильного приложения для отслеживания подписок на платные сервисы. В приложении должен быть список подписок, каждую из которых можно редактировать, удалять, а также создавать новые. Также в приложении должен быть раздел со статистикой потраченных средств на подписки. Стиль приложения минималистичный. Меню приложения расположено в нижней части экрана. Все элементы имею упрощённый дизайн и расположены по строгой сетке

Особенности дизайна:
	- минималистичный стиль
	- меню в нижней части экрана
	- строгое расположение элементов по сетке
	- монохромные цвета
	- строгие шрифты

Преимущества:
	- простой интерфейс, где всё на своих местах
	- простая цветовая схема не отвлекает на себя внимание

Недостатки:
	- скучный внешний вид
	- не очень удобно читаемые цифры
