Идея: мобильное приложение для отслеживания подписок на платные сервисы
Проблема, которую решает приложение: сохранение денег от трат на бесполезные или ненужные подписки
Целевая аудитория: платёжеспособные активные пользователи интернета
Ключевые функции:
	- добавление/удаление/редактирование подписки в списке подписок
	- рассчёт статистики по тратам на подписки
	- напоминания пользователю о списании средств
