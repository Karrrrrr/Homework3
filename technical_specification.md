# Техническое задание

## Описание проекта

Мобильное приложение, которое позволяет пользователям мониторить свои подписки на платные сервисы. Приложение хранит список существующих подписок, позволяет их редактировать, отправляет пользователю уведомления о скорых списаниях, а также собирает статистику о тратах по месяцам и за год

## Целевая аудитория

Платёжеспособные активные пользователи интернета. Молодые и взрослые люди в возрасте 18-50 лет, которые часто пользуются интернетом

## Функциональные требования

1. Функция отображения подписок: при запуске приложения пользователь попадает на главный экран, где отображается список всех подписок пользователя. Для каждой подписки отображается название сервиса, категория, дата следующего списания, сумма списания и частота списания. Список подписок можно отфильтровать по категориям. Вверху страницы отображается сумма списания за месяц и количество активных подписок.
2. Функция создания новой подписки: при нажатии на кнопку "+" открывается окно создания новой подписки. На окне есть поля для ввода названия сервиса, суммы списания и даты начала подписки. Также на окне есть плашки для выбора частоты списания и категории подписки: "Видео", "Музыка", "Облако", "Работа" и "Другое". При заполнении всех полей и нажатии кнопки "Сохранить" окно создания подписки закрывается, создаётся новая подписка и отображается в списке всех подписок на главном экране.
3. Функция редактирования существующей подписки: при нажатии на подписку на главном экране отображается окно редактирования подписки. На окне все те же поля и плашки, как на окне создания новой подписки. При изменении значений в полях и нажатии кнопки "Сохранить" окно редактирования подписки закрывается. Информация о подписке изменяется на главном экране.
4. Функция удаления существующей подписки: при нажатии на кнопку "Удалить" появляется окно подтверждение удаления. После подтверждения удаления окно редактирования подписки закрывается, подписка удаляется из списка всех подписок на главном экране.
5. Функция просмотра статистики: при нажатии на кнопку "Статистика" открывается окно статистики, в котором отображается статистика пользователя. Вверху экрана отображаются суммы, потраченные на подписки за месяц, за календарный год, за последние 12 месяцев и за всё время. Ниже отображается график расходов по месяцам. Столбцы в графике кликабельные. При нажатии на столбец отображается статистика за выбранный месяц в разрезе категорий. Внизу окна отображаются самые дорогие подписки в год с суммой, которую заплатил пользователь.
6. Функция отправки уведомлений: когда списание за одну из подписок пользователя наступит завтра, приложение отправляет пуш-уведомление пользователю, в котором уведомляет о завтрашнем списании. При нажатии на уведомление приложение открывает окно редактирование подписки, для которой наступает срок платежа.

## Нефункциональные требования

1. Функция отображения подписок: приложение должно отображать до 50 подписок на одном окне без подвисаний.
2. Функция создания новой подписки: время от нажатия кнопки "Сохранить" до создания подписки должно быть не более 1 секунды.
3. Функция редактирования существующей подписки: время от нажатия кнопки "Сохранить" до изменения подписки должно быть не более 1 секунды.
4. Функция удаления существующей подписки: время от нажатия кнопки "Удалить" до удаления подписки должно быть не более 1 секунды.
5. Функция просмотра статистики: окно статистики должно открываться с задержкой не более 1 секунды. На окне статистики не должно быть задержек при нажатии на столбцы графика.
6. Функция отправки уведомлений: уведомления должны отправляться, даже если приложение не запущено, ровно за 1 день до списания средств в 12:00 по местному времени.

## Обработка ошибок

1. Если у пользователя нет подписок, то на главном экране приложения должна отображаться надпись "Подписок ещё нет".
2. Пользователь создаёт подписку без названия: отображается всплывающая подсказка "Введите название сервиса".
3. Пользователь ещё не использовал приложение достаточно времени, чтобы отобразить статистику: если пользователь использует приложение меньше месяца, на окне статистики отображается надпись: "Недостаточно данных для отображения статистики".
4. Пользователь создаёт подписку со стоимостью 0 рублей: после нажатия на кнопку "Сохранить" отображается всплывающее окно: "Вы уверены, что хотите создать подписку с оплатой 0 рублей?". При нажатии на кнопку "Да" создаётся подписка с оплатой 0 рублей. При нажатии на кнопку "Нет" пользователь остаётся на окне создания подписки.
